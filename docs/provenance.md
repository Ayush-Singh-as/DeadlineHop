# Implementation provenance

The Python simulator, baselines, history reconstruction, Double DQN updates, training/evaluation workflow, tests, and visualizations were authored for this project. No public RL repository was cloned, forked, or copied. General dependencies provide arrays, automatic differentiation, optimizer primitives, environment interfaces, plotting, and PDF generation.

Codex assisted implementation in this workspace at the user's request. Team members should review, understand, and accurately disclose this assistance under their course's applicable rules. Algorithmic ideas are credited to research papers; implementation assistance must not be represented as unaided personal authorship.

The existing `.git` path is a protected, empty, read-only directory in this environment. It was preserved. Actual incremental development history is stored in `.development-history` and can be inspected with `git --git-dir=.development-history --work-tree=. log`. The release script creates a normal repository checkout from that history. Commits use the neutral local identity `Project implementation <project@localhost>`; they do not impersonate a team member or invent past dates.

Original PDFs are left untouched and are not included in the release archive. Public paper links are in the literature notes. Do not claim simulation scores reproduce published paper results or establish deployable physical-radio performance.
